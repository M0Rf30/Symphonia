# Symphonia TTA (True Audio) Codec

[![Docs](https://docs.rs/symphonia-bundle-tta/badge.svg)](https://github.com/M0Rf30/Symphonia/tree/rmpd-next/symphonia-bundle-tta)

True Audio (TTA1) demuxer and decoder for Project Symphonia.

**Note:** This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
