# Symphonia ALS Codec

[<img alt="Docs.rs" src="https://img.shields.io/badge/docs.rs-symphonia_codec_als-brightgreen?style=for-the-badge" height="22"/>](https://github.com/M0Rf30/Symphonia/tree/rmpd-next/symphonia-codec-als)

MPEG-4 Audio Lossless Coding (ALS) decoder for Project Symphonia.

> [!NOTE]
> This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.

The decoder is a port of the ALS decoder of FFmpeg and is bit-exact with it. The RLS-LMS extension is not supported (FFmpeg does not support it either).
