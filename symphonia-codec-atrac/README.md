# Symphonia ATRAC1 and ATRAC3 Codecs

[<img alt="Docs.rs" src="https://img.shields.io/badge/docs.rs-symphonia_codec_atrac-brightgreen?style=for-the-badge" height="22"/>](https://github.com/M0Rf30/Symphonia/tree/rmpd-next/symphonia-codec-atrac)

ATRAC1 (MiniDisc SP) and ATRAC3 (MiniDisc LP, ATRAC3 WAV/AT3, RealAudio 8 "atrc") decoders for
Project Symphonia.

> [!NOTE]
> This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
