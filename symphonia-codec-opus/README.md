# Symphonia Opus Codec

A pure-Rust, native Opus (RFC 6716) decoder for Project Symphonia. This is a from-scratch port
of the reference `libopus` decoder algorithms into safe Rust, not a wrapper/binding around
`libopus` or any other native library. See `NOTICE` for the provenance and license of the ported
algorithms (BSD-3-Clause), which coexists with this crate's own MPL-2.0 license.

> [!NOTE]
> This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
