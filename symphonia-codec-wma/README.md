# Symphonia WMA Codec

[<img alt="Docs.rs" src="https://img.shields.io/badge/docs.rs-symphonia_codec_wma-brightgreen?style=for-the-badge" height="22"/>](https://github.com/M0Rf30/Symphonia/tree/rmpd-next/symphonia-codec-wma)

Windows Media Audio 1 and 2 decoder for Project Symphonia. WMA Pro, WMA Lossless and WMA Voice are
not supported.

> [!NOTE]
> This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
