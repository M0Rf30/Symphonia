# Symphonia game audio demuxers

[<img alt="Docs.rs" src="https://img.shields.io/badge/docs.rs-symphonia_format_game-brightgreen?style=for-the-badge" height="22"/>](https://github.com/M0Rf30/Symphonia/tree/rmpd-next/symphonia-format-game)

CRI ADX demuxer for Project Symphonia. The ADX audio is decoded by the ADPCM decoder of `symphonia-codec-adpcm`.

> [!NOTE]
> This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
