# Symphonia QCP Format

[<img alt="Docs.rs" src="https://img.shields.io/badge/docs.rs-symphonia_format_qcp-brightgreen?style=for-the-badge" height="22"/>](https://github.com/M0Rf30/Symphonia/tree/rmpd-next/symphonia-format-qcp)

QCP (RIFF `QLCM`, RFC 3625) demuxer for Project Symphonia. Carries QCELP 13K and EVRC speech.

> [!NOTE]
> This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
